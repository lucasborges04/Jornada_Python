# Jornada_Python
 Projetos desenvolvidos durante a jornada python da Hashtag

Python PowerUp: Projeto de automatização de tarefas.
Obs: A posição onde o mouse da um click varia de computador para computador, por conta da resolução.
Se o seu não estiver selecionando o campo certo, temos um arquivo para pegar a posição correta de onde deve ser o click do mouse.
Basta entrar no "arquivo_posicao.py", rodar o código e deixar o mouse em cima de onde desaja.

Python Insights: Projeto de Análise de Dados.

Python IA: Inteligência Artificial criada para prever Score de Crédito.

Python Dev: Aplicação Web. Foi criado um Chat que pessoas podem conversar em difirentes lugares. Assim como o WhatsApp.
Para testar essa aplicação:
    -Execute o arquivo "main.py";
    -Entre no localhost (servidor local);
    -Entre no localhost novamente, porém, em uma guia anônima ou em outra conta do google;
    -Insira seu nome;
    -Escreva a mensagem e envie.
